# Enstitü Portal

Türkiye geneli ile il (81) ve bölge (İBBS-1, 12) düzeyinde nüfus, aile, ekonomi, fiyat, işgücü ve eğitim göstergeleri.

- **Veri kaynağı:** TÜİK Veri Portalı (SDMX API)
- **Harita sınırları:** [htastan/TRmaps](https://github.com/htastan/TRmaps) (MIT)
- **Not:** "Hesaplanmış" etiketli göstergeler TÜİK tarafından yayımlanmaz; ilgili tablolardan türetilir.

Site statiktir (`index.html` + `veri/*.js`), herhangi bir sunucu gerektirmez.
